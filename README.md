# 國語能力檢測 × 南一版課文分析｜靜態網站

此網站展示 111–115 年五、六年級國語文檢測題組與南一版課文的 **12 組待驗證候選配對**。不是官方對照表，也不是完整 35 組分析。

## GitHub Pages 部署

1. 在 GitHub 建立公開儲存庫 `ntcu-nani-reading-skill`。
2. 將此目錄的 `index.html`、`data.json`、`candidate-pairings.csv`、`README.md` 上傳至儲存庫根目錄。
3. 到 Settings → Pages，選擇 Deploy from a branch，Branch 設定 `main`、`/(root)`，儲存。
4. 等待 GitHub Pages 完成部署，使用 GitHub 提供的網站網址。

## 注意

所有配對仍待核對原始題本、題號、課文版本與全文，請勿當成已驗證結論。網站不含完整題本與教科書內文。


新版：依南一版五上、五下、六上、六下分組，附原創三段教學導讀及各年度題本 PDF 雲端硬碟連結。配對與題號仍待核對；PDF 連結的公開可見性取決於雲端硬碟分享權限。
