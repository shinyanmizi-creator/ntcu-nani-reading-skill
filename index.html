如何使用這份分析？

先依年度、年級或關鍵字找出候選題組，再比對其閱讀策略，例如人物心理、因果推論、科普說明、寓意與象徵。備課時應先查核題本原文及對應課文，確認適合後再設計教學活動。

建議教學順序：原課文閱讀 → 策略示範 → 檢測題組練習 → 跨文本比較 → 形成性評量。

資料與方法

此版本由原有資料與新增七份題本所整理的 candidate-pairings.csv 建立。資料包含年度、年級、候選篇名、題號、南一版冊別、冊次、課次、候選課文、教學連結及驗證狀態。冊次與課次已依提供的目錄圖片核對；閱讀測驗配對仍屬候選分析。各篇補充理由為依現有候選分析提出的教學比較建議，題名或內容待核對者仍須先查閱原始題本；未經核實不主張同一作者。下載 JSON 資料 · 下載 CSV 資料。
